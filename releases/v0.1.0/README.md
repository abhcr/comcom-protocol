# Comcom v0.1.0 — Experimental prototype

Version 0.1.0 demonstrated the original Comcom architecture. It is preserved byte-for-byte for reproducibility, but it is not suitable for production interoperability or security-sensitive use. See the [v0.1 advisory](../../advisories/v0.1.md).

The hashes in `sha256.json` cover every tracked v0.1 schema, registry, fixture, and specification file as they existed at commit `733a344`.
