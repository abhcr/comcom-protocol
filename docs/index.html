The protocol path

Known website in. Completed work out.

  1. 01
    Discover

    Fetch /.well-known/comcom from the business website.

  2. 02
    Match

    Select an exact versioned capability from its manifest.

  3. 03
    Validate

    Check the request locally against the published JSON Schema.

  4. 04
    Invoke

    Call the standard gateway or the declared existing API mapping.

  5. 05
    Act

    Use the typed result as the authoritative business record.
